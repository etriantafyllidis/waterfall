<p align="left">
  <strong>Summary</strong><br>
WATERFALL is a workflow for goal-free reward discovery in sparse-reward, partially observable tasks (POMDPs). Many foundation-model reward methods receive goals, task descriptions, demonstrations, or ground-truth success metrics upfront. In reveal-gated POMDPs, this information is often unavailable, since objectives, affordances and dynamics must be discovered through interaction. WATERFALL combines persona-conditioned reward synthesis, VLM-judged Swiss tournaments of visual rollouts, and history-guided refinement. Quantitative standings and qualitative behavioural digests guide mutation, escalation, and pruning as more of the environment is revealed. This enables reward discovery under observability parity, using only evidence available to the policy rather than privileged pre-disclosure of unrevealed task ontologies and environment dynamics.
</p>
